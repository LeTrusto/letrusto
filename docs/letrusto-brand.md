# LeTrusto — Brand Identity

## Brand Name

**LeTrusto**

## Business

Discovery-commerce platform for beauty, jewellery, fashion accessories, and giftable lifestyle products in India.

## Positioning

**TRENDING FINDS. EVERYDAY PRICES.**

Discover beauty, jewellery and style finds without the premium price.

## Brand Personality

- Modern
- Attractive
- Youthful
- Trustworthy
- Affordable
- Discovery-oriented
- Premium-looking without being expensive

## Avoid

- Cheap dropshipping aesthetic
- Generic marketplace clone look
- AI SaaS website appearance
- Excessive gradients / colours
- Fake urgency, fake discounts, fake reviews
- Cluttered layouts
- Overly corporate design
- Discount spam aesthetic

## Design Principle

**AFFORDABLE BUT NOT CHEAP-LOOKING.**

The UI must feel trustworthy enough for a customer to enter payment information.

## Visual Direction

### Chosen: Direction A — Minimal Premium

Clean white space, subtle warm tones, confident typography, editorial product presentation.

Feels like: curated boutique meets affordable everyday commerce.

#### Colour Palette

| Token | Value | Usage |
|-------|-------|-------|
| Primary | `#18181b` (Zinc 900) | Primary actions, headings, wordmark |
| Accent | `#d4a574` (Warm Gold) | CTAs, highlights, badges |
| Accent Dark | `#b8915e` | Hover state for accent |
| Rose | `#e11d48` (Rose 600) | Sale price, urgency, errors |
| Success | `#16a34a` (Green 600) | In stock, confirmations |
| Surface | `#ffffff` | Card backgrounds |
| Surface Soft | `#fafaf9` (Stone 50) | Page background |
| Surface Muted | `#f5f5f4` (Stone 100) | Subtle containers |
| Text Primary | `#18181b` (Zinc 900) | Headings, body |
| Text Secondary | `#52525b` (Zinc 600) | Supporting copy |
| Text Muted | `#a1a1aa` (Zinc 400) | Captions, placeholders |
| Border | `#e4e4e7` (Zinc 200) | Card borders, dividers |
| Border Hover | `#d4d4d8` (Zinc 300) | Interactive borders |

#### Typography

- Primary: Inter (Google Fonts) — clean, modern, highly legible
- Mono: Geist Mono (retained from existing setup, for prices/codes)
- Headings: 700–900 weight, tight letter-spacing
- Body: 400–500 weight, generous line-height

#### Logo

Temporary text wordmark: **LeTrusto** in Inter 800 weight, zinc-900.

Final logo to be supplied/approved separately.

### Alternative: Direction B — Modern Playful (not selected)

Rounded shapes, soft pastel accents, bouncy micro-interactions, emoji-adjacent warmth.

### Alternative: Direction C — Editorial / Social-Commerce (not selected)

Magazine-style layouts, bold typography, influencer-forward cards, story-like product reveals.

## Initial Categories

1. Jewellery (artificial/fashion jewellery)
2. Hair & Style (hair accessories, styling tools)
3. Beauty Tools (brushes, organizers, mirrors)
4. Accessories (bags, scarves, sunglasses)
5. Gifts (giftable lifestyle products)

## Target Audience

Young women (18–35) in India, mobile-first, value-conscious, style-aware.
